# Plano de Estudo – Módulo 1: Design para Aplicativos Mobile

## Duração recomendada: 3 semanas (1º ciclo de estudo: 14/04 a 30/04)

## Objetivo Geral:
Capacitar o aluno a criar interfaces mobile modernas, acessíveis e funcionais, respeitando princípios de design UI/UX, arquitetura visual e boas práticas de componentes reutilizáveis.

## Conteúdo Programático

### Semana 1 – Fundamentos de UI/UX e Design Responsivo
Princípios de UI (User Interface) e UX (User Experience)

Hierarquia visual, alinhamento, contraste, espaçamento, tipografia

Navegação e fluxo de telas

Grids, wireframes e prototipação

Acessibilidade em apps (cores, tamanho, navegação por teclado)

### Semana 2 – Ferramentas e Componentização
Utilização de Figma para prototipação de telas

Introdução ao Material Design 3 e Flutter Widgets visuais

Componentes reutilizáveis e customização de temas

Uso de ícones, cores e fontes consistentes (ThemeData)

Aplicação de responsividade para múltiplos tamanhos de tela

### Semana 3 – Animações, Layouts Avançados e Boas Práticas
Animações com Flutter (AnimatedContainer, Hero, PageRouteBuilder)

Organização de layouts complexos com Flex, Stack, MediaQuery

Dark Mode, acessibilidade e boas práticas

Uso de pacotes como flutter_screenutil, google_fonts, flutter_svg

## Ferramentas e Plataformas
Figma – Para design visual e prototipação

Flutter + Dart – Para desenvolvimento prático das telas

Material Design Guidelines – https://m3.material.io


## Projetos Práticos Propostos

### Projeto 1: Aplicativo de Lista de Compras
- Objetivo: Criar um app com layout limpo e componentes reutilizáveis.
- Tela 1: Tela inicial com título, lista de compras e botão de adicionar.
- Tela 2: Tela de adicionar item com campos de texto e botão de salvar.
- Técnicas aplicadas: ListView, Card, TextField, ThemeData, validação de formulários.

### Projeto 2: Catálogo de Produtos com Navegação e Detalhes
- Objetivo: Trabalhar com layout grid e navegação entre telas.
- Tela 1: Lista de cards de produtos com imagem, nome e preço.
- Tela 2: Tela de detalhes com descrição e botão de compra.
- Técnicas aplicadas: GridView, Hero animation, custom widgets, routes.

### Projeto 3: UI de App de Clima (Estilo Google Weather)
- Objetivo: Criar uma interface atraente com foco em dados visuais e responsividade.
- Tela única: Visualização do clima atual, animações de fundo, previsão em cards.
- Técnicas aplicadas: Stack, animacoes simples, alinhamento com MediaQuery, uso de ícones customizados.
